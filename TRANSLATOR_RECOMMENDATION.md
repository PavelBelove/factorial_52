## 🏗️ Архитектура решения

### Фоновая обработка (async)

```
┌─────────────────────────────────────────┐
│         Игрок делает ход                │
│                                         │
│  1. Игрок: "Иду в гильдию"             │
│     → Сразу в контекст (RU) ────────┐  │
│                                      │  │
│  2. ГМ обрабатывает контекст         │  │
│     (с русским ходом)                │  │
│                                      │  │
│  3. ГМ отвечает (RU narrative)       │  │
│     → Сразу в контекст (RU) ────┐   │  │
│     → Отправка боту              │   │  │
│                                  │   │  │
│  4. ФОНОВО запускается:          │   │  │
│     TranslatorAgent(             │   │  │
│       player: "Иду в гильдию",   │   │  │
│       gm: "ГМ ответ..."          │   │  │
│     )                            │   │  │
│                                  ▼   ▼  │
│  5. Перевод готов (1-2s)    ┌─────────┐│
│     → Замена в Redis        │ EN turn ││
│     → При следующем ходе    └─────────┘│
│        ГМ получает EN ход                │
└─────────────────────────────────────────┘

Результат: 80-90% ходов в контексте переведены
```

### Технический стек

**1. Redis для кэширования:**
```python
# Structure
redis_key = f"turn:{session_id}:{turn_number}"
redis_value = {
    "player": "EN text",
    "gm": "EN narrative",
    "timestamp": ...,
    "status": "translated"
}
```

**2. Async queue (Celery/RQ):**
```python
@task
async def translate_turn(session_id, turn_number, ru_text):
    # 1. Call Grok Fast translator
    en_text = await grok_translate(ru_text)
    
    # 2. Update Redis
    await redis.set(f"turn:{session_id}:{turn_number}", en_text)
    
    # 3. Update DB (async)
    await db.update_turn_translation(session_id, turn_number, en_text)
```

**3. Context manager (модификация):**
```python
def get_raw_turns(session_id, num_turns=7):
    turns = []
    for turn_id in recent_turn_ids:
        # Try Redis first (cached translation)
        cached = redis.get(f"turn:{session_id}:{turn_id}")
        if cached and cached["status"] == "translated":
            turns.append(cached)  # Use EN
        else:
            # Fallback to DB (might be RU if translation pending)
            turns.append(db.get_turn(session_id, turn_id))
    return turns
```
