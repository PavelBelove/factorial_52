# Команды для меню бота

Скопируйте и вставьте в BotFather (команда /setcommands):

```
stats - Характеристики персонажа
inventory - Инвентарь и экипировка
retry - Повторить последний ход
undo - Отменить последний ход
session - Статистика сессии
cost - Расходы на API
help - Правила и справка
```

**Примечание:** /start намеренно не включён в меню, чтобы не сбросить игру случайно.

---

# Настройка в BotFather

1. Найдите @BotFather в Telegram
2. Выберите вашего бота
3. Используйте команды:
   - `/setdescription` — вставьте полное описание
   - `/setabouttext` — вставьте короткое описание
   - `/setcommands` — вставьте список команд
   - `/setuserpic` — загрузите картинку (опционально)

4. Готово! Бот настроен.
