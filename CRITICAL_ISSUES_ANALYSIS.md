### 3. ❌ ГМ получает ТОЛЬКО список имен, БЕЗ полных квантов

**Что видит ГМ (из терминала):**
```
# Доступные кванты (последние обновления)

- **Гильдия_Авантюристов**: [concept]
- **Зачистка_Подгорья**: [event]
- **Кинжал_рунный**: [item]
...
```

**Что должен получать (по концепту):**

```markdown
# Активная память (кванты)

## Лира
**Тип:** character
**Описание:** Магистр Академии Рендала, преподаватель магии. 
Отец пропал в Зачарованном Лесу возле Подгорья. 
Попросила Пола найти информацию о нем.
**Связи:**
- =Академия_Рендала= (работает магистром)
- =Отец_Лиры= (ищет)
- =Квест_Поиск_Отца= (заказчик)

## Академия_Рендала
**Тип:** location
**Описание:** Академия магии в городе Рендал. Белокаменные башни...
**Связи:**
- =Лира= (магистр)
- =Рендал= (находится в городе)
```

**КРИТИЧНО:** Без полных квантов ГМ:
- Не знает кто такая Лира
- Не может различить NPC
- Не понимает контекст
- Не может запросить связанные кванты

**Вопросы:**
- Где формируется секция "Активная память (кванты)"?
- Почему вместо нее только "Доступные кванты" (synopsis)?
- Проверить `context_manager._format_quants(active_quants)`
