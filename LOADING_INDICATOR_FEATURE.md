# Индикатор загрузки с анимацией

## Что сделано

Реализована система индикации загрузки с анимированными армянскими символами (Аревахач) для улучшения пользовательского опыта при долгих ответах LLM.

## Основные компоненты

### 1. LoadingIndicator (`telegram/utils/loading_indicator.py`)
Класс для отображения анимированного индикатора загрузки:
- Использует армянские символы U+058D (֍) и U+058E (֎)
- Обновляется каждые 2 секунды
- Максимум 10 символов, затем начинает заново
- Может менять текст на лету (например, "Думаю..." → "Модель перегружена, пробую еще раз...")
- Заменяет индикатор на финальный текст по завершении

### 2. Мультиязычная локализация
Добавлены строки в `core/localization/`:
- `get_thinking_message()` - "Думаю..." / "Thinking..."
- `get_creating_story_message()` - "⏳ Создаю новый мир..." / "⏳ Creating a new world..."
- `get_retrying_message()` - "Модель перегружена, пробую еще раз..." / "Model overloaded, trying again..."

### 3. Логика повтора при таймауте
- 2 попытки при таймауте или ошибке сети
- При повторной попытке текст индикатора меняется на "Модель перегружена, пробую еще раз..."
- Задержка 2 секунды между попытками

## Где применяется

### 1. Создание нового мира (`telegram/handlers/menu.py`)
- Показывает "⏳ Создаю новый мир и готовлю приключение..."
- Анимированные символы Аревахач
- При таймауте автоматически повторяет запрос
- По завершении заменяет индикатор на ответ ГМ

### 2. Ответы во время игры (`telegram/bot.py`)
- Показывает "Думаю..."
- Анимированные символы
- Логика повтора при таймауте
- Заменяет индикатор на ответ агента

## Преимущества

1. **Решает проблему таймаута**: Пользователь видит, что бот работает, даже если инференс занимает 2-3 минуты
2. **Автоматический повтор**: При перегрузке модели бот автоматически повторяет запрос
3. **Визуальная обратная связь**: Армянские символы создают эффект "загрузки"
4. **Мультиязычность**: Все надписи локализованы для русского и английского языков
5. **Плавная замена**: Индикатор заменяется на финальный текст, а не отправляется новое сообщение

## Пример работы

```
[Пользователь отправляет сообщение]

Думаю...
֍

[Через 2 секунды]

Думаю...
֍֎

[Через 2 секунды]

Думаю...
֍֎֍

[Если таймаут на первой попытке]

Модель перегружена, пробую еще раз...
֍

[По завершении - индикатор заменяется на ответ]

📖 Глава #5

Ты входишь в таверну...
```

## Технические детали

- Таймаут API увеличен до 180 секунд (3 минуты)
- Анимация работает асинхронно через `asyncio.Task`
- Корректная остановка при получении ответа
- Обработка ошибок редактирования сообщений Telegram
