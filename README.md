## 🌟 Особенности

### Factorial 52! — Абсолютная уникальность

Число уникальных перестановок колоды из 52 карт больше, чем атомов во Вселенной:

**80 658 175 170 943 878 571 660 636 856 403 766 975 289 505 440 883 277 824 000 000 000 000**

Каждая история в каждом мире — абсолютно уникальна. Ваша книга никогда не повторится.

### 🎴 Карты Судьбы

Колода из 52 карт — это источник случайности и сюжетных поворотов, благодаря которому история остаётся непредсказуемой. Рассказчик не знает результата проверки заранее — он узнаёт его вместе с вами.

### 🧠 Живая Память

- **Долговременная память** — Рассказчик помнит всех персонажей, события, места

- **Сюжетные линии** — множественные параллельные сюжеты развиваются органично
- **Последствия** — ваши решения влияют на мир

### 🌍 Множество миров

- 🎓 **Академия Магии** — волшебная академия, тайны и обучение
- 🌸 **Исекай** — перенос в фантастический мир
- ⚔️ **Меч и Магия** — классическое фэнтези
- 🏛️ **Неоклассика** — мифология в современном мире
- ☢️ **Фоллаут** — постапокалипсис
- 🎭 **Городское Фэнтези** — магия в современном городе

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.10+
- Telegram Bot Token
- Anthropic API Key (Claude 3.5 Sonnet)

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/plexmem.git
cd plexmem

# Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt

# Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env и добавьте свои ключи
```

### Конфигурация

Создайте файл `.env` с следующими параметрами:

```env
# Telegram
TELEGRAM_BOT_TOKEN=your_telegram_bot_token

# Anthropic API
ANTHROPIC_API_KEY=your_anthropic_api_key

# Database (опционально)
DATABASE_URL=sqlite:///data/plexmem.db

# Logging
LOG_LEVEL=INFO
```

### Запуск

```bash
# Запуск Telegram бота
python -m telegram.main

# Или через скрипт
./run.sh
```

## 🎮 Использование

### Основные команды

- `/menu` — главное меню (новое приключение, библиотека, настройки)
- `/stats` — характеристики героя
- `/inventory` — инвентарь и экипировка
- `/undo` — отменить последнюю страницу
- `/retry` — переписать последнюю страницу
- `/session` — статистика истории
- `/help` — справка

### Как играть

1. **Отправьте** `/menu` чтобы открыть главное меню
2. **Выберите** "✨ Новое приключение"
3. **Выберите мир** для вашей истории
4. **Создайте героя** — опишите его внешность, историю, характер
5. **Действуйте** — просто пишите что делает ваш герой
6. **Наслаждайтесь** уникальной историей!

### Прямая речь с Рассказчиком

Сообщение `[в квадратных скобках]` — это обращение напрямую к Рассказчику вне истории:

- `[Хочу больше экшена]` — настройка тона
- `[Мой герой — девушка]` — исправление ошибок
- `[Что я вижу вокруг?]` — уточнения

## ⚙️ Технологии

### AI & LLM

- **[Anthropic Claude 3.5 Sonnet](https://www.anthropic.com/)** — основной ИИ для повествования
- **Многоагентная архитектура** — специализированные агенты для разных задач
- **Квантизированная память** — умное сжатие истории без потери информации

### Backend

- **Python 3.10+** — основной язык
- **aiogram 3.x** — фреймворк для Telegram бота
- **SQLAlchemy** — ORM для работы с базой данных
- **Jinja2** — шаблонизация промптов

### Database

- **SQLite** — легковесная БД (можно заменить на PostgreSQL)
- Схема включает: пользователей, сессии, персонажей, инвентарь, сообщения, память

## 🎴 Механики: Factorial 52!

### Характеристики

- ♠ **Сила** — ближний бой, воля, запугивание
- ♥ **Магия** — колдовство, мудрость, общение
- ♦ **Стойкость** — защита, выносливость, торговля
- ♣ **Ловкость** — дальний бой, акробатика, скрытность

### Проверки

```
Результат = (карта1×10 + бонус1) + (карта2×10 + бонус2) + характеристика
```

**Бонусы:**
- Масть совпадает с проверкой: **+20**
- Цвет совпадает (нет совпадения масти): **+10**
- Нет совпадений: **0**

### Пороги сложности

| Сложность | Легко | Средне | Сложно | Очень сложно |
|-----------|-------|--------|--------|--------------|
| Порог     | 100 + ср | 150 + ср | 200 + ср | 250 + ср |

Где **ср** — среднее значение характеристик персонажа

### Особые комбинации

- 🃏🃏 **Два туза** — божественный успех
- 🂢🂢 **Две двойки** — катастрофа

### Развитие

За успешную проверку: **+1 XP** к характеристике  
При **10 XP**: +1 к характеристике, +1 к HP и мане

## 📝 Настройки

### Сложность

- **Лёгкая** — пороги снижены (шаг 40)
- **Нормальная** — стандартный баланс (шаг 50)
- **Сложная** — пороги повышены (шаг 40, база выше)

### Контент-фильтр

- **Безопасный** (по умолчанию) — без эротики, романтика за кадром
- **16+** — лёгкая романтика и эротика
- **18+** — взрослый контент (требуется информированное согласие)

## 🛠️ Разработка

### Структура проекта

Подробная документация по архитектуре в [ABOUT.md](ABOUT.md)

### Добавление нового мира

1. Создайте директорию в `data/worlds/your_world/`
2. Добавьте `config.json` с метаданными мира
3. Создайте `gm_system.md` с системным промптом (поддерживает Jinja2)

```bash

```

### Логирование

Логи сохраняются в `logs/`:
- `logs/agents/` — логи агентов (GM, квантизатор и т.д.)
- `logs/bot.log` — логи бота
- `logs/errors.log` — ошибки

## 📊 API Costs

Проект использует Anthropic Claude API. Примерная стоимость:

- **Claude 3.5 Sonnet**: ~$3 per 1M input tokens, ~$15 per 1M output tokens
- Средний ход: ~5K tokens input + ~1K tokens output = ~$0.03
- 100 ходов: ~$3

Используйте `/cost` для просмотра текущих расходов.
