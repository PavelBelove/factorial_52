# PlexMem - Предиктивно-ассоциативная память для LLM

Система долговременной памяти для AI-агентов, основанная на семантических квантах и предиктивной активации.

## Особенности

- **Предиктивная активация памяти**: агент запрашивает кванты, релевантные следующему ходу
- **Семантические связи**: кванты связаны осмысленными отношениями, а не статистически
- **Фиксированный контекст**: память не растёт в контексте модели
- **Модульная архитектура**: разделение ГМ, квантователя и суммаризатора
- **Масштабируемость**: от SQLite до PostgreSQL+Redis

## Установка

```bash
# Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установить зависимости
pip install -r requirements.txt

# Настроить конфигурацию
cp .env.example .env
# Отредактировать .env, добавить API ключи
```

## Запуск

```bash
# Запуск FastAPI сервера
cd core
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000

# Запуск Telegram бота (Phase 2)
cd telegram
python bot.py
```

## Архитектура

```
core/
├── agents/        # ГМ, квантователь, суммаризатор
├── managers/      # Менеджеры памяти и контекста
├── database/      # Работа с БД
├── models/        # Pydantic модели
├── llm/           # LLM клиент (OpenRouter)
└── api/           # FastAPI endpoints
```
