# 🎲 Исправления отображения механик для ГМ

**Дата:** 2026-01-19  
**Проблема:** ГМ не показывал карты и статы игрока, только сравнивал итоговые значения с порогами.

---

## 📋 Проблемы

### 1. ❌ ГМ не показывал разбивку расчётов

**Было:**
```
ГМ: "С **245 единицами магической силы** процесс идёт..."
```

**Проблема:**
- ГМ видел только итоговое значение: `♥: 245 (легко 170, сложно 295)`
- Не видел карты, бонусы, статы
- Не понимал что показывать игроку

---

### 2. ❌ Ошибка API при создании предметов

**Ошибка:**
```
ValidationError: Input should be 'weapon', 'armor', 'accessory' or 'consumable' [type=enum, input_value='item']
```

**Причина:** ГМ использовал неправильный тип `'item'` вместо допустимых.

---

### 3. ❌ /retry телепортировал героя

**Проблема:**
- Ход 14: Герой в лаборатории, ГМ запросил `Лира`, `Академия`
- Ход 15: Герой в гильдии
- `/retry` откатывает к ходу 14
- Новый ход 15: Герой снова в лаборатории! ❌

**Причина:** Запрошенные кванты хода 14 не очищались и попадали в контекст.

---

## ✅ Решения

### 1. Расширен формат контекста для ГМ

**Файл:** `core/managers/context_manager.py`

**Было:**
```
♠: 210 (легко 155, сложно 275)
```

**Стало:**
```
♠: 240 (30+20 + 120+0 + 70 стат) → легко 155, сложно 275
     └─┬─┘ └──┬──┘ └─┬─┘
   карта1  карта2   характеристика
   +бонус  +бонус   персонажа
```

**Код:**
```python
# Show breakdown: card1 + card2 + stat
card1_str = f"{check['card1_value']}+{check['card1_bonus']}" if check['card1_bonus'] > 0 else str(check['card1_value'])
card2_str = f"{check['card2_value']}+{check['card2_bonus']}" if check['card2_bonus'] > 0 else str(check['card2_value'])
breakdown = f"({card1_str} + {card2_str} + {check['stat']} стат)"

checks_str.append(f"{suit_icon}: {total} {breakdown} → легко {easy_thresh}, сложно {hard_thresh}")
```

### 5. Исправлен /retry (очистка квантов)

**Файл:** `core/database/db_manager.py`

```python
def delete_last_turn(self, session_id: int) -> bool:
    # ... existing code ...
    
    # Clear requested_quants from the NEW last turn (previous turn)
    # This prevents stale quants from confusing GM on retry
    if db_session.current_turn > 0:
        prev_turn = session.query(TurnDB).filter(
            TurnDB.session_id == session_id,
            TurnDB.turn_number == db_session.current_turn
        ).first()
        
        if prev_turn:
            prev_turn.requested_quants = "[]"  # Clear quant requests
    
    session.commit()
```
