## Что можно сделать прямо сейчас

### Запуск системы:
```bash
# API
python run_api.py

# Bot
python run_bot.py
```

### Использование бота:
1. `/start` или `/menu` - открыть меню
2. Выбрать язык (для новых пользователей)
3. Создать новую игру → выбрать мир (например, Isekai)
4. Играть!
5. Сохранить игру в слот
6. Загрузить игру из слота

### Добавление нового мира:
1. Создать папку в `data/worlds/{world_name}/`
2. Добавить `config.json` с описанием
3. Добавить `initial_quants.json`, `initial_summary.md`
4. (Опционально) `quantizer_instructions.md` для специфичной логики

### Добавление нового языка:
1. Создать файл `core/localization/{lang_code}.py`
2. Наследоваться от `BaseLocalization`
3. Реализовать все методы
4. Добавить в `core/config.py` в `available_localizations`

## Технические детали

### Изменения в БД:
- `users` таблица: `+language`, `+current_world`
- `sessions` таблица: `+world_id`, `+slot_number`, `+is_saved`, `+saved_at`, `+save_name`

### Новые API endpoints:
- `GET /worlds` - список миров
- `GET /worlds/{world_id}` - конфигурация мира
- `GET /users/{user_id}/saves` - сохранения пользователя
- `POST /sessions/{session_id}/save` - сохранить игру
- `POST /sessions/{session_id}/load` - загрузить игру

### Архитектурные решения:
1. **Шаблонизация промптов**: Quantizer промпт поддерживает расширение через world-specific инструкции
2. **Модульность**: Миры полностью независимы друг от друга
3. **Масштабируемость**: Легко добавлять новые миры и языки
4. **Совместимость**: Старые сессии не сломаются (будут иметь world_id="isekai" по умолчанию)
