### 2. ❌ ГМ неправильно показывает значения проверок

**Проблема:**
```
ГМ: "С **245 единицами магической силы** процесс идёт..."
```

**Причина:** ГМ не понимает что 245 - это готовый результат проверки, а не ресурс.

**Решение:** Добавлены инструкции в промпт ГМ:

```markdown
❌ НЕПРАВИЛЬНО: "С **245 единицами магической силы**..."
✅ ПРАВИЛЬНО: "С **проверкой магии 245 против сложности 275**..."

**НЕ называй это "единицами магической силы"** - это ПРОВЕРКА, не ресурс!
```

### 3. ❌ Глюк сюжета при /retry (герой телепортируется)

**Проблема:**
- Ход 14: Герой в лаборатории, ГМ запросил квант `Лира`
- Ход 15: Герой в Гильдии
- `/retry`: откат к ходу 14
- Новый ход 15: Герой снова в лаборатории! ❌

**Причина:** 
При удалении хода 15, запрошенные кванты хода 14 (`Лира`, `Академия`) остаются и попадают в контекст нового хода 15, сбивая ГМ.

**Решение:**
Исправлен `delete_last_turn()` - теперь при undo очищаются `requested_quants` предыдущего хода:

```python
# Clear requested_quants from the NEW last turn
if db_session.current_turn > 0:
    prev_turn = session.query(TurnDB).filter(...).first()
    if prev_turn:
        prev_turn.requested_quants = "[]"  # Clear quant requests
```
