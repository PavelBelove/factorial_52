### 3. Ограничения знаний NPC (КРИТИЧНО!)

```prolog
npc_knowledge_rule :-
    npc_knows_only_what_they_saw,
    npc_knows_what_they_were_told_by_someone_present,
    npc_does_not_know_events_without_them,
    npc_does_not_know_player_thoughts.
```

**Проблема (ДО):**
- NPC знают всё обо всём
- Элина откуда-то знает про Подгорье
- Все знают про тролля

**Решение:**
```prolog
rumor_system :-
    big_events_become_rumors,
    rumors_spread_fast_in_city,
    npcs_hear_rumors_not_facts,
    details_get_distorted_in_rumors.
```

**Пример:**

✅ **Правильно:**
> Элина: "Слухи в Академии быстрее ветра! Лира растрепала — какой-то студент-герой завалил орка в Подгорье. А Торгард из гильдии добавил про дрон и пули."

❌ **Неправильно:**
> Элина: "Ты убил тролля-вожака газовыми гранатами в Подгорье 23 января."

### 4. Система маркеров квантов (КРИТИЧНО!)

**Три концепта — НЕ путать:**

1. **Маркер** `=Академия_Рендала=` — внутренний тег в тексте ГМ
2. **ID кванта** `Академия_Рендала` — имя в базе данных (без пробелов)
3. **Отображаемое имя** `Академия Рендала` — для игрока (с пробелами, читаемое)

**Как использовать:**

```prolog
you_write("Ты входишь в =Академия_Рендала="),
player_sees("Ты входишь в Академию Рендала"),
markers_invisible_to_player.
```

**Правильное использование:**

```prolog
correct_markers :-
    "=Лира= улыбается",                  % ✅ 
    "в =Таверна_Золотой_Телец=",         % ✅
    "твой друг =Драг=",                  % ✅
    "задание про =Зачарованный_Лес=".    % ✅
```

**Неправильное использование:**

```prolog
wrong_markers :-
    "= Лира =",              % ❌ Пробелы внутри
    "=Лира",                 % ❌ Нет закрывающего маркера
    "Лира=",                 % ❌ Нет открывающего
    "Таверна =Золотой Телец=". % ❌ Пробелы в ID
```

**Когда использовать:**

✅ Отмечать:
- NPC из памяти
- Локации из памяти
- Предметы из памяти
- Квесты из памяти
- Всё из active quants или synopsis

❌ НЕ отмечать:
- Обычные объекты ("стол", "меч", "дверь")
- Новых NPC (только что представленных)
- Обычные существительные
