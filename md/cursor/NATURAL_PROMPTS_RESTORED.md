#### 🔴 Длина и детальность (NEW!)

```markdown
Минимальная длина ответа: 3000 СИМВОЛОВ (не токенов)!

Стиль: Сергей Лукьяненко
- Городское фэнтези
- Яркие сенсорные детали
- Внутренний голос персонажей
- Динамичный темп
```

**Принципы описаний:**
- Что видит: визуальные детали, освещение, цвета
- Что слышит: звуки, голоса, музыка
- Что чувствует: температура, текстуры, вес
- Что обоняет: ароматы, запахи
- Кто присутствует: NPC с описанием
- Что доступно: объекты, выходы

**Примеры:**
- ✅ ХОРОШО: Детальное описание (~500+ символов)
- ❌ ПЛОХО: "Ты в академии. Одна подходит." (~30 символов)

#### 🔴 Знания NPC (NEW!)

```markdown
NPCs ЗНАЮТ ТОЛЬКО:
1. То, что видели своими глазами
2. Слышали лично от кого-то
3. Узнали из общедоступных источников

NPCs НЕ ЗНАЮТ:
- События без их участия
- Мысли других
- Детали, которые не могли узнать
```

**Система слухов:**
- Важные события → слухи
- Слухи быстро распространяются
- NPCs слышат СЛУХИ, не ФАКТЫ
- Детали искажаются

**Примеры:**

✅ **Правильно:**
> "Слухи в Академии быстрее ветра! Лира рассказала — какой-то студент зачистил Подгорье..."

❌ **Неправильно:**
> "Ты убил тролля-вожака газовыми гранатами 23 января в 14:30..."

---

#### 🔴 Система маркеров (NEW!)

**Три концепта:**

1. **Маркер** `=Академия_Рендала=` — внутренний тег (невидим игроку)
2. **ID** `Академия_Рендала` — имя в БД (без пробелов)
3. **Имя** `Академия Рендала` — для игрока (с пробелами)

**Использование:**

Ты пишешь: `"Ты входишь в =Академия_Рендала="`  
Игрок видит: `"Ты входишь в Академию Рендала"`  
Система: загружает квант Академия_Рендала

**✅ Правильно:**
```
"=Лира= улыбается"
"в =Таверна_Золотой_Телец="
"твой друг =Драг="
```

**❌ Неправильно:**
```
"= Лира ="           // пробелы
"=Лира"              // нет закрывающего
"=Золотой Телец="    // пробелы в ID
```
