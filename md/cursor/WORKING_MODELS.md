# Рабочие модели для PlexMem из России

## ✅ Работающие модели через OpenRouter:

### Meta Llama (рекомендуется)
```
meta-llama/llama-3.1-70b-instruct
meta-llama/llama-3.1-8b-instruct
```

### Mistral AI  
```
mistralai/mistral-7b-instruct
mistralai/mixtral-8x7b-instruct
```

### Qwen
```
qwen/qwen-2-72b-instruct
```

## ❌ НЕ работают из России:

- `x-ai/grok-*` - блокировка xAI
- `anthropic/claude-*` - блокировка Anthropic
- `google/gemini-*` - проблемы с эндпоинтами

## Рекомендация:

Используйте **meta-llama/llama-3.1-70b-instruct** - хорошее качество и доступность.
