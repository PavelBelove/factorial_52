## 📋 Формат синопсиса

```json
{
  "create_Маша": {
    "type": "npc",
    "synopsis": "Официантка в таверне =Золотой_Телец=, город =Архонт=",
    "body": {...},
    "links": {...}
  }
}
```

## 🎯 Как работает

1. **Квантователь создает кванты с кратким synopsis**
2. **Система собирает кванты за последние 30 ходов**
3. **ГМ и Квантователь видят список:**
   ```
   # Доступные кванты (последние обновления)
   
   - **Маша**: Официантка в таверне =Золотой_Телец=, город =Архонт=
   - **Лира**: Главная героиня, дочь пропавшего исследователя =Зачарованный_лес=
   ```
4. **Используют маркеры для запроса связанных квантов**
5. **Избегают создания дублей** (видят что квант уже существует)

## 🔧 Миграция БД

```bash
# Добавить synopsis
sqlite3 data/plexmem.db "ALTER TABLE quants ADD COLUMN synopsis VARCHAR(500);"

# Добавить aliases
sqlite3 data/plexmem.db "ALTER TABLE quants ADD COLUMN aliases JSON DEFAULT '[]';"
```
