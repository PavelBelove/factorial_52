## ✅ Что реализовано:

### 1. Модели данных
- **Card**: Карта из колоды (2-A, 4 масти)
- **Character**: Персонаж с характеристиками, HP, маной, инвентарем
- **Item**: Предметы с бонусами к характеристикам
- **CharacterDB**: Таблица БД для персонажей

### 2. Колода карт
- 52 карты без джокеров
- Раздача пар (N=2 пары по умолчанию)
- Автоматический reset при исчерпании

### 3. Расчеты
- **Пороги сложности**: Легко/Средне/Сложно/Очень сложно
- **Проверки вне боя**: Все масти, все пары, бонусы за цвет/масть
- **Бой**: Все действия (ближняя/дальняя атака, защита), комбо
- **Особые события**: Фигуры, тузы, двойки (только мирное время)
- **Создание персонажа**: 5 карт, расчет характеристик

### 4. MechanicsManager
- Раздача карт
- Расчет всех проверок и боевых действий
- Создание/управление персонажами
- **Автопрокачка**: +1 XP за успех → 10 XP = +1 характеристика
- **Прокачка HP/маны**: +1 при повышении любой характеристики
- Применение изменений от ГМ
- Управление инвентарем (add/remove/equip/unequip)

### 5. Интеграция
- **TurnOrchestrator**: Проверяет наличие персонажа, тянет карты, передает данные
- **ContextManager**: Форматирует механики для ГМ (~300 токенов)
- **GM prompt**: Инструкции по работе с механиками

### 6. Тестирование
✅ Все тесты прошли успешно! (см. `test_mechanics.py`)

## 📋 Формулы

### Создание персонажа:
```
Характеристика = номинал × 5 + (10 если масть совпадает)
HP = spades + diamonds + clubs
Mana = hearts × 3
```

### Проверки (вне боя):
```
Результат = (карта1 + карта2) × 10 + характеристика + бонусы
Бонус за одинаковый цвет: +10 (красные) / -10 (черные)
Бонус за одинаковую масть: +20 (красные) / -20 (черные)
```

### Бой:
```
Значение = (карта1 + бонус1) + (карта2 + бонус2) + характеристика
Бонус для карты: +20 (совпадение масти) ИЛИ +10 (одинаковый цвет)
Урон = атака - защита
```

### Автопрокачка:
```
Успешная проверка → +1 XP к используемой характеристике
10 XP → +1 к характеристике, +1 max HP, +1 max mana, XP = 0
```

## 🎮 Как это работает

### Создание персонажа:
1. Система тянет 5 карт
2. ГМ объясняет игроку правила
3. Игрок распределяет или просит ГМ сделать это
4. ГМ возвращает в `response_data`:
   ```json
   {"create_character": {"spades": 45, "hearts": 70, ...}}
   ```
5. Система создает персонажа в БД

### Обычный ход:
1. Система тянет 2 пары карт (4 карты)
2. Рассчитывает все проверки для всех мастей
3. Рассчитывает все боевые действия
4. Форматирует и передает ГМ (~300 токенов)
5. ГМ выбирает нужный результат и описывает сюжетно
6. ГМ возвращает изменения в `response_data`:
   ```json
   {
     "checks_used": [{"suit": "spades", "success": true}],
     "hp": -15,
     "mana": -10,
     "gold": 100,
     "inventory": {"add": [...], "remove": [...]},
     "equip": ["Меч"]
   }
   ```
7. Система применяет изменения:
   - Обновляет HP, ману, золото
   - Добавляет/удаляет предметы
   - Начисляет XP при успешных проверках
   - Автоматически повышает характеристики при 10 XP
