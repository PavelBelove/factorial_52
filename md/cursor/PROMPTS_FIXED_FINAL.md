### 2. ✅ Quantizer Prompt ИСПРАВЛЕН

**База:** Working master prompt

**Усилены/добавлены:**

#### 📝 Synopsis - ОБЯЗАТЕЛЬНОЕ поле:
```json
{
  "synopsis": "девушка-лиса, студентка =Академия=, флиртует с =Пол="
}
```
- Всегда заполнено (не пусто!)
- Максимум маркеров на другие кванты
- Одна строка с максимумом контекста

#### 🏷️ Маркеры ВЕЗДЕ:
- ❌ НЕ "студентка" → ✅ "студентка =Академия_Рендала="
- ❌ НЕ "дал обещание" → ✅ "обещал =Квест_Поиск_Отца="
- ❌ НЕ "учится магии" → ✅ "учится =Факультет_Магии_Иллюзий="

**В synopsis, body, links - везде!**

#### 🔍 Проверка дубликатов:
**1 сущность = 1 квант!**
- Проверять active quants
- Проверять synopsis list
- Fuzzy matching для похожих названий
- **UPDATE существующего** вместо создания дубликата

#### 🎨 Культурные референсы:
```json
{
  "body": {
    "reference": "Холо из Волчица и пряности, но лисичка"
  }
}
```
- Создает стабильный живой образ
- ГМ сразу понимает характер
- Несколько токенов вместо длинного описания
