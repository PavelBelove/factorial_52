## 🔧 Что исправлено

### 1. Агрессивная очистка процессов
**Было:** Скрипты не убивали старые процессы полностью  
**Стало:** Убиваем всё связанное с `uvicorn`, `run_api`, `run_bot`

```bash
pkill -9 -f "uvicorn|run_api|run_bot" 2>/dev/null || true
```

### 2. Убрана проверка порта
**Было:** Скрипт падал если порт занят  
**Стало:** Убиваем процессы на порту, потом запускаем

### 3. Добавлен `lsof` с проверкой
**Было:** Ошибка если `lsof` не установлен  
**Стало:** Проверяем наличие команды перед использованием

```bash
if command -v lsof &> /dev/null; then
    lsof -ti:8000 | xargs kill -9 2>/dev/null || true
fi
```
