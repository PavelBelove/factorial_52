## 🎮 Особенности реализации

### Telegram бот включает:

1. **Команды:**
   - `/start` - создание сессии
   - `/help` - справка
   - `/stats` - статистика (ходы, кванты)
   - `/undo` - отмена хода (заглушка)

2. **Функции:**
   - Автоматическое создание сессий
   - Маппинг telegram_id → session_id
   - Индикатор "печатает..."
   - Разбивка длинных сообщений
   - HTML форматирование

3. **Обработка ошибок:**
   - Timeout
   - API недоступен
   - Неизвестные ошибки
   - Graceful degradation

### Скрипт запуска `start_plexmem.sh`:

1. **Проверки:**
   - Наличие .env
   - Наличие venv (создаёт если нет)
   - Зависимости
   - Свободные порты

2. **Запуск:**
   - API в фоне → логи в `logs/api.log`
   - Бот в фоне → логи в `logs/bot.log`
   - Ждёт готовности API
   - Показывает статус

3. **Остановка:**
   - Ctrl+C корректно останавливает оба процесса
   - Cleanup функция
