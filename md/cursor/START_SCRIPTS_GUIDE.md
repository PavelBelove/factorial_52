# 🚀 PlexMem - Скрипты запуска

## Доступные скрипты

### 1. `start_console.sh` ⭐ **РЕКОМЕНДУЕТСЯ для отладки**
**Все логи видны в консоли в реальном времени**

```bash
./start_console.sh
```

**Что делает:**
- ✅ Убивает старые процессы
- ✅ Запускает API и Bot
- ✅ Показывает ВСЕ логи в терминале
- ✅ Ctrl+C для остановки

**Когда использовать:**
- 🔍 Отладка проблем
- 👀 Нужно видеть что происходит
- 🐛 Поиск ошибок

---

### 2. `start_plexmem.sh` ⭐ **Для продакшна**
**Красивый запуск с логами в файлы**

```bash
./start_plexmem.sh
```

**Что делает:**
- ✅ Проверяет зависимости
- ✅ Создаёт директории
- ✅ Убивает старые процессы
- ✅ Запускает API и Bot (логи в файлы)
- ✅ Показывает статус

**Логи:**
```bash
tail -f logs/api.log        # API
tail -f logs/bot.log        # Bot
tail -f logs/plexmem_*.log  # Полные логи системы
```

**Когда использовать:**
- ✅ Обычный запуск
- ✅ Продакшн режим
- ✅ Фоновая работа

---

### 3. `start_debug.sh` 🔍 **DEBUG режим**
**Экспорт DEBUG_VERBOSE=True + вывод в консоль**

- ✅ Показывает подробные логи
- ✅ Вывод в консоль

**Когда использовать:**
- 🐛 Нужны ОЧЕНЬ подробные логи

---

### 4. `start_simple.sh` ⚡ **Быстрый запуск**
**Минимальный, без лишних проверок**

```bash
./start_simple.sh
```

**Что делает:**
- ✅ Убивает старые процессы

- ⚡ Нужно быстро запустить

## 🛑 Остановка всех процессов

### Быстрая остановка:
```bash
pkill -9 -f "uvicorn|run_api|run_bot"
```

### Или через порт:
```bash
lsof -ti:8000 | xargs kill -9
```

## 📊 Проверка статуса

### Проверить что запущено:
```bash
ps aux | grep -E "uvicorn|run_api|run_bot" | grep -v grep
```

### Проверить порт:
```bash
lsof -i:8000
```

### Последние логи:
```bash
tail -50 logs/api.log
tail -50 logs/bot.log
tail -100 logs/plexmem_$(date +%Y%m%d).log
```

## 🆘 Типичные проблемы

### ❌ "Port 8000 already in use"
**Решение:**
```bash
pkill -9 -f "uvicorn|run_api|run_bot"
lsof -ti:8000 | xargs kill -9
```

### ❌ "venv not found"
**Решение:**
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### ❌ Сервис сразу падает
**Проверь логи:**
```bash
tail -50 logs/api.log
```

**Типичные причины:**
- Отсутствует `.env` файл
- Неправильные API ключи
- Ошибка в коде (проверь синтаксис)
