## 🔧 Рекомендации

### 1. Увеличить частоту Quantizer
✅ **СДЕЛАНО:** `raw_turns_trigger = 3` (было 5)

Теперь Quantizer будет срабатывать:
- Ход 3, 6, 9, 12, 15, 18, 21...
- Вместо: Ход 5, 10, 15, 20...

### 2. Постобработка имён
Добавить в `memory_manager.py`:
```python
def _normalize_quant_name(self, name: str) -> str:
    """Replace spaces with underscores in quant names."""
    return name.replace(" ", "_")
```

### 3. Избегать дубликатов
Добавить проверку перед созданием:
```python
if quant_id exists and type different:
    append to existing instead of creating new
```

### 4. GM должен давать имена важным персонажам
- Если персонаж важен → дать имя
- Если безымянный → не ждать что Quantizer создаст квант
- Лучше: "Эльфийка Сильвия" вместо "эльфийка"
