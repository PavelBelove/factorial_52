## 🔍 Почему Quantizer не создал Character и Inventory?

### CharacterCreation инструкция:
```markdown
instruction_for_quantizer: 
"Как только игрок подтвердил создание персонажа, ОБЯЗАТЕЛЬНО:
1) Создай квант 'Character' с полным описанием
2) Создай квант 'Inventory' для инвентаря
3) Добавь в CharacterCreation ссылку на Character"
```

### Что произошло:
1. **Ход 1-2:** CharacterCreation был в контексте GM
2. **Ход 3:** Игрок подтвердил создание ("Меня зовут Пол...")
3. **Ход 5:** Quantizer сработал, НО:
   - CharacterCreation **НЕ БЫЛ** в `active_quants` для Quantizer
   - GM не запросил CharacterCreation на ходу 3-5
   - Quantizer не видел специальной инструкции

### Логика orchestrator:
```python
# Quantizer получает только те кванты, которые GM запросил
active_quants = self._get_active_quants(session_id)

# CharacterCreation был только на ходах 1-2
# На ходу 5 GM запрашивал: Character, Inventory, Драг, ...
# Но их не существовало → пустой active_quants для Quantizer
```

### Вывод:
**Quantizer никогда не видел CharacterCreation!**  
Он не мог выполнить инструкцию, т.к. она не была в контексте.

## 🔴 Критические проблемы

### 1. CharacterCreation не попадает в контекст Quantizer
**Причина:** GM перестал запрашивать CharacterCreation после хода 2.

**Решение:**
- Добавить CharacterCreation в `active_quants` принудительно для Quantizer на ходах 1-5
- ИЛИ: Создать Character/Inventory автоматически в orchestrator после подтверждения

### 2. Пробелы в именах квантов
**Примеры:**
- `Серебряный Родник` ❌ вместо `Серебряный_Родник`
- `Гильдия Искателей` ❌ вместо `Гильдия_Искателей`
- `Дезерт Игл` ❌ вместо `Дезерт_Игл`

**Причина:** DeepSeek V3.2 игнорирует правила именования в промпте.

**Решение:**
- Постобработка: заменять пробелы на подчёркивания в `memory_manager.py`
- Усилить промпт с критичными примерами

### 3. Quantizer срабатывает редко
**Настройка:** `raw_turns_trigger = 5` (каждые 5 ходов)

**Фактически:** 1 раз за 21 ход

**Почему?**
Проверю логику:

```python
    await self._run_quantizer(...)
```
