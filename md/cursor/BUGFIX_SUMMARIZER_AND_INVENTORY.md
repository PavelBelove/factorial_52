## ❌ Проблема #1: Суммаризатор не запускается

### Симптомы:
```
2026-01-21 09:06:55 - core.orchestrator - INFO - Running Summarizer agent
2026-01-21 09:06:55 - core.orchestrator - INFO - Summarizer: not needed yet
```

**После 15 ходов summary всё ещё пустой!**

### Причина:
- Порог был `raw_turns_max = 7`
- После 15 ходов суммаризатор должен был сработать **дважды**
- Но после суммаризации старые ходы **НЕ УДАЛЯЛИСЬ**
- Результат: суммаризатор срабатывал 1 раз, дальше count сырых ходов не менялся

## ✅ Исправление #1: Суммаризатор

### Изменения в конфиге:

**Было:**
```python
raw_turns_min: int = 4   # Минимум сырых ходов
raw_turns_max: int = 7   # Максимум перед запуском
```

**Стало:**
```python
raw_turns_keep: int = 5  # Сколько оставлять после суммаризации
raw_turns_max: int = 10  # Когда запускать суммаризатор
```

**Логика:**
1. Когда сырых ходов >= 10 → запускается суммаризатор
2. После успешной суммаризации → удаляем старые, оставляем только 5 последних
3. Через 5 ходов (всего 10) → снова запускается суммаризатор

**Пример:**
- Ход 10: суммаризатор, удалить ходы 1-5, остаётся 6-10 (5 ходов)
- Ход 15: суммаризатор, удалить ходы 6-10, остаётся 11-15 (5 ходов)
- Ход 20: суммаризатор, и так далее...

### Код изменения:

**Файл:** `core/orchestrator.py`

```python
logger.info(f"Summarizer completed in {mode} mode")

# Trim old raw turns after successful summarization
deleted_count = self.db.trim_old_turns(
    session_id,
    keep_last_n=settings.raw_turns_keep
)

if deleted_count > 0:
    logger.info(f"Trimmed {deleted_count} summarized turns, keeping last {settings.raw_turns_keep} raw turns")
```

## ✅ Исправление #2: Дедупликация + Стакование

### Логика добавления предметов:

**Файл:** `core/mechanics/mechanics_manager.py`

```python
def _add_item_to_inventory(char, item_data, changes_log):
    """
    1. Проверка на точный дубль (id, type, bonus, description)
       → Если дубль - пропустить
    
    2. Проверка на стакуемый предмет (Зелье, Зелье_X2)
       → Если найден стак - увеличить счётчик
       → Зелье + Зелье = Зелье_X2
       → Зелье_X2 + Зелье = Зелье_X3
    
    3. Иначе - добавить новый предмет
    """
```

### Логика удаления предметов:

```python
def _remove_item_from_inventory(char, item_id, changes_log):
    """
    1. Если предмет имеет _X5 суффикс → декремент до _X4
    2. Если _X2 → декремент до базового имени (без суффикса)
    3. Если без суффикса → удалить полностью
    """
```
