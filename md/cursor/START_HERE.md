Бот уже запущен и ждёт подключения.

### 2. Отправь команду /start
Бот создаст твою игровую сессию.

Просто пиши свои действия, ГМ будет отвечать.

- `/help` - справка

## 🎯 Конфигурация

### Файл: `.env`

Модели можно настроить отдельно для каждого агента:

```bash
# Модели по умолчанию (быстрые)
GM_MODEL=x-ai/grok-4.1-fast
QUANTIZER_MODEL=x-ai/grok-4.1-fast
SUMMARIZER_MODEL=x-ai/grok-4.1-fast

# Альтернативные модели (мощнее, но медленнее)
# GM_MODEL=x-ai/grok-4
# QUANTIZER_MODEL=x-ai/grok-4
# SUMMARIZER_MODEL=x-ai/grok-4
```

### Параметры памяти:
```bash
MAX_QUANTS_PER_REQUEST=10      # Сколько квантов в контексте
RAW_TURNS_MIN=4                # Минимум сырых ходов
RAW_TURNS_MAX=7                # Максимум сырых ходов
QUANTIZER_TRIGGER_TURNS=7      # Как часто обновлять память
```

## ❓ Troubleshooting

### Проблема: API не запускается
**Решение:**
```bash
# Проверить порт
lsof -i :8000

# Убить процесс если занят
kill -9 <PID>
```

### Проблема: Бот не отвечает
**Решение:**
1. Проверь что API запущен
2. Проверь логи бота: `tail -f logs/bot.log`
3. Проверь токен в `.env`

### Проблема: Ошибка "No endpoints found"
**Решение:** Модель неправильная. Проверь список:
```bash
python test_models.py
```

### Проблема: Timeout при обращении к LLM
**Решение:** OpenRouter может быть перегружен. Подожди минуту и попробуй снова.

## 📈 Как работает память

1. **Кванты создаются автоматически**
   - ГМ упоминает NPC, локации, предметы
   - Квантователь сохраняет их в память
   - Связи формируются семантически

2. **Предиктивная активация**
   - ГМ запрашивает кванты для следующего хода
   - В контекст попадают только релевантные
   - Память "дрейфует" по сюжету

3. **Суммаризация**
   - Каждые 7 ходов история конденсируется
   - Старые события "высушиваются"
   - Кванты сохраняются как якоря
