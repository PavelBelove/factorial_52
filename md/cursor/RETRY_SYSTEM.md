# Система повторов и обработки ошибок Telegram

## Проблема

При работе с Telegram Bot API иногда возникают таймауты при отправке/редактировании сообщений, даже если LLM уже сгенерировал ответ. Это приводит к потере ответа и необходимости начинать игру заново.

## Решение

### 1. Автоматические повторы (3 попытки)

Бот автоматически пытается доставить ответ 3 раза с паузой 2 секунды между попытками.

**Реализация:**
```python
async def _send_response_with_retry(
    self, 
    message: Message, 
    preparing_msg: Message, 
    formatted_reply: str,
    max_attempts: int = 3
):
    """Send response with retry logic for Telegram API timeouts."""
    for attempt in range(max_attempts):
        try:
            # Try to edit/send message
            ...
            return  # Success!
        except Exception as e:
            if attempt < max_attempts - 1:
                await asyncio.sleep(2)  # Wait before retry
            else:
                # All attempts failed - inform user
                await self._safe_edit(preparing_msg, "❌ Не удалось доставить ответ...")
```

### 2. Команда `/retry`

Если автоматические повторы не помогли, пользователь может вручную повторить последний запрос.

**Использование:**
```
Пользователь: Мой персонаж Пол...
Бот: ❌ Не удалось доставить ответ. Попробуй: /retry

Пользователь: /retry
Бот: 🔄 Повторяю запрос: "Мой персонаж Пол..."
Бот: ⏳ Готовлю ответ...
Бот: 🎲 Ход #4 ...
```

**Реализация:**
- Бот сохраняет последнее сообщение каждого пользователя в `self.last_user_messages`
- При `/retry` создается "фейковое" сообщение с сохраненным текстом
- Запрос обрабатывается как обычное сообщение

### 3. Безопасное редактирование сообщений

Все редактирования сообщений (включая ошибки) делаются через `_safe_edit()` с повторами.

**Реализация:**
```python
async def _safe_edit(self, msg: Message, text: str, max_attempts: int = 3):
    """Safely edit message with retries."""
    for attempt in range(max_attempts):
        try:
            await msg.edit_text(text)
            return
        except Exception:
            if attempt < max_attempts - 1:
                await asyncio.sleep(1)
            else:
                # If can't edit, send new message
                try:
                    await msg.answer(text)
                except:
                    logger.error("Failed to send error message")
```

## Преимущества

1. **Не теряем прогресс**: Ответ LLM сохраняется, даже если Telegram API таймаутит
2. **Автоматические повторы**: 3 попытки доставить ответ без участия пользователя
3. **Ручной retry**: Пользователь может повторить запрос без потери контекста
4. **Не нужно начинать игру заново**: `/start` больше не единственный выход при ошибках
5. **Лучший UX**: Понятные сообщения о том, что делать при ошибке

## Технические детали

- **Хранение последних сообщений**: `Dict[int, str]` в памяти бота
- **Количество попыток**: 3 для отправки ответа, 3 для редактирования
- **Задержка между попытками**: 2 секунды для ответа, 1 секунда для редактирования
- **Fallback**: Если не можем отредактировать, отправляем новое сообщение
